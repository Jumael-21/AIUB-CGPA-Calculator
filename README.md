\## ✨ Features



\- 🧮 \*\*Accurate GPA Calculation\*\* - Uses official AIUB grading scale (A+ = 4.00 to F = 0.00)

\- 📊 \*\*Semester \& Cumulative GPA\*\* - Calculate both current semester and overall CGPA

\- 💾 \*\*Save \& Load\*\* - Persistent storage using localStorage

\- 📱 \*\*Responsive Design\*\* - Works perfectly on desktop, tablet, and mobile

\- 🎯 \*\*Previous Records\*\* - Include past academic performance for accurate CGPA

\- 🔄 \*\*Real-time Updates\*\* - Instant calculation as you input grades

\- 🎨 \*\*Beautiful UI\*\* - Modern, clean interface with AIUB branding

\- 📈 \*\*Performance Insights\*\* - Grade interpretation and academic guidance

\## 🏗️ Installation \& Setup



\### Prerequisites

\- Node.js 18+ 

\- npm or yarn



\### Clone \& Install

```bash

\# Clone the repository

git clone https://github.com/jumael-21/aiub-cgpa-calculator.git



\# Navigate to project directory

cd aiub-cgpa-calculator



\# Install dependencies

npm install



\# Start development server

npm run dev

```



\### Build for Production

```bash

\# Create production build

npm run build



\# Preview production build

npm run preview

```



\## 📖 How to Use



1\. \*\*Add Courses\*\*: Click "Add Course" to input your semester courses

2\. \*\*Enter Details\*\*: 

&nbsp;  - Select credit hours (1-4)

&nbsp;  - Choose your grade from the dropdown

3\. \*\*Previous Records\*\* (Optional): Include your previous CGPA and total credit hours

4\. \*\*View Results\*\*: See your semester GPA and cumulative GPA in real-time

5\. \*\*Save Progress\*\*: Click "Save Calculation" to store your data locally
